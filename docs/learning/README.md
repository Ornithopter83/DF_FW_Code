세 문서는 Word에서 열 수 있는 DOCX 형식이다. 각 장에는 요점 정리 또는 학습 점검 질문을 넣었다. 향후 방향은 개선 후보와 완료 기준을 제안하며 기존 활성 작업을 재개하지 않는다.

## 작성 근거와 확인 기록

- 기존 개념 안내의 내용을 기본편으로 구성했다. 앞선 안내에서 언급한 docs/PROJECT_LEARNING_GUIDE.md는 이번 작업의 로컬 읽기에서 존재하지 않아 대화에 작성된 내용을 바탕으로 복원했다.
- 사용자 승인 범위에서 Main/Rod 주요 진입점·모듈·통신·제어·OTA와 TestModule 연결·표시·업데이트 소스를 읽었다.
- DOCX ZIP/OOXML 구조, 제목·본문 스타일, 기본편과 심화편의 1~9장 대응을 확인했다.
- 수동 페이지 구획은 기본편 6개, 심화편 9개, 향후 방향 2개다. 실제 Word 페이지 수를 확인한 결과는 아니다.
- documents 스킬의 render_docx.py 실행은 soffice.exe를 찾지 못해 실패했다. 실제 페이지 렌더링과 이미지 확인은 미실행이며, 페이지 확인을 생략한 전달에 대한 사용자 승인을 요청했다.
- 펌웨어 빌드·테스트·장비 제어·플래시·commit·push는 수행하지 않았다.
- 기존 활성 구현 잔여 작업 0개를 변경하지 않았다. 새로운 구현 작업서는 만들지 않았다.
