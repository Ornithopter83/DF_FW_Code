# 작업 20

TM 릴 재연결 시 버전 정보 갱신

## 목표와 범위

TM이 MAIN과 연결된 상태에서 ROD가 나중에 연결되거나 재연결될 때 상단 버전 정보를 다시 조회한다.

## 세부 작업

### A. ROD 연결 전이 시 버전 재조회

- 완료일: 2026-10-15
- TM에서 `$20` 연결 상태가 끊김에서 연결로 바뀌면 `$10%` 버전 조회를 요청한다.
- 초기 MAIN 연결 초기화 도중에는 별도 조회를 보내지 않아 기존 초기 버전 조회와 중복되지 않게 했다.
- 조회 중/송신 실패 상태를 상단 ROD·IMU 버전 라벨에 표시하고 로그를 남긴다.
- 근거: 기존 `$20` 처리는 연결 상태만 갱신했고, `$10%` 조회는 MAIN 초기화 시점에만 실행했다. MAIN은 `$10%` 수신 후 연결된 ROD에 PID 21 버전 요청을 보내며 ROD 응답을 PC에 전달한다.
- 코드 변경은 완료했으나 빌드, 실행 및 실제 연결 재현은 수행하지 않았다.

## 진행

작업 20-A 완료. 남은 문자 작업 0개.
