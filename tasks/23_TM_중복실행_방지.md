# 작업 23

TM 중복 실행 방지

## 목표

- 동일한 Windows 사용자 세션에서 DF TestModule의 일반 실행 인스턴스가 하나만 동작하도록 한다.
- 두 번째 실행 시 기존 프로그램을 유지하고 사용자에게 이미 실행 중임을 알린다.
- `--self-test` 실행 경로는 GUI 단일 인스턴스 잠금과 분리해 기존 자동 검사 진입 동작을 유지한다.

## 세부 작업

### A. TM 일반 실행 단일 인스턴스 잠금

- (완료: 2026-10-16) TM 일반 실행 진입점에 `Local\DFTestModule_SingleInstance` named mutex를 추가했다. 첫 인스턴스가 GUI 실행 동안 mutex를 보유한다.
- (완료: 2026-10-16) 이미 실행 중이면 새 MainForm을 열지 않고 안내 메시지를 표시한 뒤 종료한다.
- (완료: 2026-10-16) `--self-test` 분기를 mutex 검사보다 앞에 유지해 기존 self-test 호출 동작을 변경하지 않았다.
- 확인 근거: `testModule/Program.cs`의 진입 분기, mutex 생성, 중복 실행 반환 및 GUI 종료 시 mutex 해제를 소스에서 확인했다.
- 빌드·실행 시험은 AGENTS.md의 사용자 사전 승인 정책에 따라 수행하지 않았다.

## 진행

작업 23-A 구현 잔여 0개, 검증 잔여 1개. 중복 실행 시 두 번째 GUI가 생성되지 않는지 실제 실행 확인은 빌드·실행 승인 후 진행한다.

## 시험 방법

1. TM을 실행하고 같은 EXE를 다시 실행했을 때 두 번째 GUI 대신 안내 메시지가 표시되는지 확인한다.
2. 첫 번째 TM을 종료한 뒤 다시 실행했을 때 정상적으로 시작되는지 확인한다.
3. `--self-test`를 실행했을 때 기존 self-test 경로가 그대로 동작하는지 확인한다.

## 결과

- 2026-10-16: Windows named mutex를 이용한 일반 실행 단일 인스턴스 처리를 구현했다. 빌드, GUI 실행, self-test는 미실행이다.
