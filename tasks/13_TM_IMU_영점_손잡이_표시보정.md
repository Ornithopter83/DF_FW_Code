# 작업 13

TM IMU 영점 방향 및 릴 손잡이 표시 보정

## 목표

0점 보정 후 FRONT가 좌우로 치우치지 않는 기준 자세를 표시하고, 릴 손잡이 표시 회전량을 기존의 1.3배로 늘린다.

## 요청과 승인

- 사용자: IMU 0점 보정 후 FRONT가 우측으로 기울어 보임, 손잡이 회전량을 1.3배 조정 요청.
- 관련 코드 조회·분석 및 두 표시 보정 수정 승인. 이어서 빌드까지 승인.
- 범위: TM 표시 코드 수정, 기존 NuGet 잠금 문제의 빌드 준비와 TM Release 게시 1회.
- 테스트·장비 조작·FW 빌드·commit/push는 포함하지 않는다. 실패 재시도는 AGENTS.md의 새 승인 정책을 따른다.

## 기준 및 경계

- 시작 Git 상태: main...origin/main, 변경 없음. 기존 원격 백업 커밋 bc8e551 / 태그 backup/local-20261002-143949는 보존한다.
- ImuOrientationView의 카메라는 (3.2, 2.4, 6.5)로 오른쪽에 있고, 0점에서는 Roll/Pitch/Yaw 차이가 0이 된다. 카메라의 측면 위치가 FRONT 축의 화면상 우측 편향을 만든다.
- 손잡이 표시 회전은 $14 수신 이벤트마다 기존 18도씩 증가한다.
- 기존 영점 계산·센서 수치·프로토콜·엔코더 원값·펌웨어와 물리 모터 출력은 수정하지 않는다.

## 세부 작업

### A. 표시 보정 (완료: 2026-10-02)

- 카메라 X를 3.2에서 0으로 바꾸어 FRONT 기준축의 좌우 투영 편향 제거. Y/Z는 기존 값을 유지한다.
- HandleRotationScale=1.30을 두고 표시 회전 스텝을 18*1.30=23.4도로 조정한다.
- 확인 근거: 해당 상수·카메라 선언을 기존 문자열과 일치할 때에만 수정한 파일 편집 명령 exit 0.
- 빌드 및 실제 화면/장비 확인은 이 단계에서 미실행.

### B. 승인된 빌드 (완료: 2026-10-02)

- 기존 공통 analyzer 설정에 맞게 NuGet 잠금을 명시 복원 1회로 재평가한다.

- 성공/실패와 출력 위치를 사실대로 기록한다. 실패 시 승인 없는 재시도는 하지 않는다.
