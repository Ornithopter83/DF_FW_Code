# 작업 15

TM LED 디밍 패턴 선택 및 순환 색 표시

## 목표와 범위

사용자 요청: 디밍 패턴 최대 6, 기본값 6(Default), 순환 색을 우측에 표기. 코드 수정 후 2026-10-12 사용자가 Release 빌드를 승인했다. GUI/장비 확인은 실행하지 않았다.

## 조사 기준

- 펌웨어는 $06의 액션 3에서 두 자리 매개변수를 colorMany로 해석한다.
- 1~6에서는 빨강·초록(Lime)·파랑·노랑·청록·자홍 중 첫 번째부터 설정값까지 순환한다.
- 7 이상은 이번 UI에서 선택하지 않는다. 펌웨어의 색상 순환 코드와 장비 출력은 수정하지 않는다.

## 세부 작업

### A. 패턴 옵션과 전송 분리 (완료: 2026-10-02)

- 디밍 액션에서 일반 색상 행을 숨기고 디밍 패턴 선택 행을 표시한다.
- 패턴 1~6만 제공하며 최초 선택은 6(Default)다.
- 패턴 선택 오른쪽에 실제 색상 순서를 화살표로 표시하고 선택 변경 시 갱신한다.
- 디밍 전송은 패턴값을 사용하며 일반 켜짐/점멸 전송은 기존 색상값을 유지한다.
- 명령 생성에서도 디밍 범위를 1~6으로 제한한다. 공통 최대값·기본값 상수는 DeviceProtocol에 둔다.
- 대체 전 UI/명령 생성 코드는 deprecated/testmodule/led-dimming-before-presets-20261002에 보존한다.
- 완료 근거: 기존 함수 및 검증 선언 일치 조건을 확인한 코드 편집 명령 exit 0. 실제 빌드·테스트 결과는 아니다.

### B. 빌드 확인 (완료: 2026-10-12)

- 사용자 승인 후 TM Release 게시 1회 성공 (exit 0).
- 산출물: `bin/testmodule/Release/DFTestModule_V041.exe`, 83,113,790 bytes.
- 상세 결과: `docs/build/BUILD_REVALIDATION_2026-10-12.md`.
- 실제 옵션 배치·선택·장비 출력 확인은 미실행 상태로 기록한다. 승인 없는 테스트/재시도는 하지 않는다.

## 진행

A/B 완료. 잔여 번호 작업 1개(12), 잔여 문자 2개(12-H/I).
