# 작업 21

TM IMU 재연결 시 상태와 버전 갱신

## 목표와 범위

TM 실행 중 ROD는 계속 연결된 상태에서 IMU가 분리됐다가 다시 연결될 때 IMU 연결 상태와 상단 IMU 버전을 갱신한다.

## 세부 작업

### A. IMU 재연결 전이 시 버전 재조회

- 완료일: 2026-10-15
- TM이 `$21` IMU 상태 프레임에서 끊김→연결 전이를 감지하면 `$10%`를 보내 IMU 버전을 다시 조회한다.
- IMU 연결이 끊기면 상단 IMU 버전을 `IMU 미연결`로 표시한다.
- 초기 MAIN 연결 초기화 중에는 기존 초기 버전 조회와 중복 요청하지 않는다.
- 초기 명령 묶음 전체 재전송은 하지 않는다. `$080%`가 IMU 데이터 출력을 끄는 명령이고 다른 항목도 초기화 성격이므로, 재연결 전이에 대응하는 버전 요청만 실행한다.
- 근거: ROD 펌웨어는 IMU 수신 데이터를 1초 주기로 확인하고 상태 변경 시 PID 21을 전송한다. MAIN은 이를 PC의 `$21` 프레임으로 전달한다. TM은 기존에 연결 표시만 갱신하고 버전 재조회는 하지 않았다.
- 코드 수정 완료. 빌드, 실행, 실제 분리·재연결 시험은 미실행이다.
